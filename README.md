# Longshot — Privacy Policy

Privacy policy for the **Longshot (Scrolling Screenshot)** Chrome extension.

- [English](PRIVACY.md)
- [简体中文](PRIVACY.zh-CN.md)

**Summary:** Longshot collects nothing and transmits nothing. Capture,
stitching, editing and export all happen locally in your browser. There is no
server, no account, and no analytics.
