# Changelog

All notable changes to Longshot will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and the project follows [Semantic Versioning](https://semver.org/).

## [Unreleased]

## [0.4.0] - 2026-10-13

### Added

- Line, highlight, numbered markers, dashed strokes and opaque masking.

### Changed

- Annotation selection and common editing controls aligned with FixedShot.
- Magnifiers render from original-resolution pixels; resizing is linked with zoom.

### Fixed

- Text input focus, Chinese IME handling, re-editing, wrapping and undo/redo.
- Crop boundaries, middle-button panning and independently scaled PNG export.

## [0.3.0]

### Added

- Zoom-in lens for long captures, fit-width mode, shortcut hints.

## [0.2.0] - 2026-08-21

### Added

- Full-page scrolling capture for documents and dominant inner scrollers.
- Crop, drawing, arrow, shape, text, pixelate, and magnifier tools.
- PNG and JPEG export, clipboard copy, and configurable output size.
- English and Simplified Chinese interfaces.
- Local-only processing with no analytics, accounts, or host permissions.
